== why this is inert for the fork's serving path ==
It changes behavior only when BOTH opt-ins are on: `return_assistant_tokens_mask=True` AND prompt truncation
(`truncate_prompt_tokens`, or a negative value resolving through max_input_tokens). Neither is on for the
fork's Qwen serving. And the only behavior that changes was already broken (mask describing different
positions than the tokens it labels), so no working behavior is altered.
