== what the fix actually does ==
Scheduler: replaces the single `cache_config.block_size` with a per-group
  `group_block_sizes = tuple(g.kv_cache_spec.block_size for g in kv_cache_config.kv_cache_groups)`
and slices each group with `cdiv(num_external_tokens, group_block_size)`, `zip(..., strict=True)`.
Worker: `group_to_layers` is built from `kv_cache_config.kv_cache_groups` at construction instead of
  `register_kv_caches` hardcoding `{0: all layers}`.
=> Before: every layer was attributed to group 0, so `group_to_layers.get(group_idx, [])` returned [] for
   every group index >= 1 and the fill loop silently filled ONLY group 0 of a multi-group (HMA) layout,
   while block counts were computed with one global block size. Bench-only connector: the defect corrupted
   *decode benchmark* fidelity, not serving.
